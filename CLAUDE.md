# Working with me — communication preferences

I'm new to software development, GitHub, git, and Claude Code. I'm actively
learning and want to understand what's happening — so teach as you go.

## How to talk to me
- Explain things at a beginner level, but don't dumb them down. Assume I'm
  smart and motivated; I just don't know the jargon yet.
- The first time you use a technical term (repo, branch, commit, push, PR,
  merge, environment variable, etc.), define it in one plain sentence.
- When you run git/GitHub commands or change project structure, tell me in
  plain language what you did and why it mattered.
- Keep explanations short and concrete; offer more depth rather than dumping
  it all at once.
- When there's a decision to make, explain the trade-offs simply and give me
  a clear recommendation.

## Goal
Help me build things AND come away understanding a bit more about how repos,
GitHub, and Claude Code work each time.
